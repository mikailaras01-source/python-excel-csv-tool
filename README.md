# Excel & CSV Data Processing Tool

A Python-based tool for cleaning, validating, combining, and organizing Excel and CSV files.

## Features

- Upload and combine multiple Excel and CSV files
- Preview uploaded data
- Check for missing values and invalid data
- Detect duplicate records
- Validate quantities and prices
- Calculate sales revenue
- Export processed data to an Excel workbook
- Generate data quality reports

## Technologies

- Python
- Pandas
- OpenPyXL
- Streamlit

## How to Run

1. Install Python.
2. Install the required dependencies:

   ```bash
   pip install pandas openpyxl streamlit
   ```

3. Start the web application:

   ```bash
   python -m streamlit run app.py
   ```

## Project Purpose

This project demonstrates practical Python skills in spreadsheet processing, data validation, and workflow automation.

It was developed as a portfolio project using example data.
